# Weather Search Application

A Python command-line application that allows users to search for the current weather in a city using the Open-Meteo API.

## Description

The user enters the name of a city. The application uses the Open-Meteo Geocoding API to find the city's latitude and longitude. It then uses the Open-Meteo Weather Forecast API to retrieve the current weather.

The application displays:

- Temperature
- Weather condition
- Humidity
- Wind speed

## APIs Used : Geocoding API

The Geocoding API is used to find the latitude and longitude of the city entered by the user.

### Weather Forecast API

The Weather Forecast API is used to retrieve the current weather information using the city's latitude and longitude.
